# Dados

Esta pasta guarda arquivos de persistencia simples em texto.

## Arquivos

- `posts.txt`: banco de posts do jogo, no formato `tipo;texto` (tipo = `real` ou `falso`). Linhas com `#` sao comentarios.
- `recorde.txt`: melhor pontuacao registrada (salva ao fim de cada partida).
- `ranking.txt`: ranking de jogadores (previsto para a entrega final).
- `README.txt`: arquivo legado; manter por compatibilidade se necessario.

## Observacao

Evite versionar dados pessoais reais dos jogadores.
